# Apple Checkout Page – Flexbox Version

## Overview

This project is a pure responsive implementation of the Apple Shop Checkout Page challenge from devChallenges. It was built using semantic HTML5 and modern CSS with Flexbox for layout and custom media queries for responsiveness.

The application consists of two main sections:
- Product Summary
- Checkout Form

The layout adapts smoothly across desktop, tablet, and mobile devices.
